# Awesome BIM Datasets [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A curated list of open datasets for **Building Information Modeling (BIM)** and the built environment: IFC models, point clouds and scan-to-BIM data, floorplans, 3D city models, energy and performance data, construction-site data, synthetic scenes, and ML benchmarks.

Browse with search and filters on the website: [https://nbharathik.github.io/awesome-bim-datasets](https://nbharathik.github.io/awesome-bim-datasets/)

## Related lists

- [Awesome CityGML](https://github.com/OloOcki/awesome-citygml): The definitive list of open semantic 3D city models, 215M+ freely available buildings across 22 countries, with per-dataset licenses. Go here for every national/city LoD2 dataset beyond the highlights listed above.
- [awesome-bim](https://github.com/SikongSphere/awesome-bim): Curated list of BIM software, libraries and tools, with a small open-dataset section.
- [awesome-point-cloud-analysis](https://github.com/Yochengliu/awesome-point-cloud-analysis): Papers and datasets for point cloud analysis broadly, beyond the building domain.

## License notes

- Licenses shown are those stated by the dataset providers at the time of listing. **Always verify the current terms at the source before use**, especially for commercial projects.
- *Custom (research)* means access requires agreeing to a dataset-specific research terms-of-use, usually via a request form.
- This list itself is released under [CC0 1.0](LICENSE).

## Contributing

Contributions are welcome. Found a dataset that's missing, or a dead link? Please open an issue or a pull request, see [CONTRIBUTING.md](CONTRIBUTING.md). All data lives in [`data/datasets.json`](data/datasets.json); run `python3 scripts/build.py` to regenerate the README and website from it.
